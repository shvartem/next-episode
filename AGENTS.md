# Правила проекта

Перед работой прочитать и соблюдать [архитектуру проекта](docs/architecture.md).

## Размер файлов и линтер

- Файл — не больше 120 строк (проверяет ESLint `max-lines`). Если файл разрастается, выносить части по правилам архитектуры: подкомпоненты в дочерние папки, логику в Presenter, типы в `types.ts`. Не сжимать код ради лимита.
- После изменений запускать `npm run lint` и исправлять ошибки.
