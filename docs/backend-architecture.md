# Архитектура backend

- `server/index.ts` создаёт приложение Express, подключает общие middleware и маршруты, запускает сервер.
- `server/routes/<имя>/` содержит HTTP-обработчик и его локальные функции разбора параметров. Обработчик вызывает Task и формирует HTTP-ответ.
- `server/tasks/<действие>/` содержит Interactor и функции, используемые только в этом сценарии. Task принимает типизированные параметры и работает независимо от Express.
- `server/entities/` содержит серверные объекты состояния. Кеш TVmaze управляет хранением и сроком жизни записей.
- `server/tvmaze.ts` обращается к внешнему API и использует кеш. Контракты фронтенда и сервера лежат в `shared/` и доступны через `#shared/*`.
