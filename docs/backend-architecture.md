# Архитектура backend

- `server/index.ts` создаёт приложение Express, подключает общие middleware и маршруты, запускает сервер.
- `server/routes/<имя>/` содержит роутер, контроллер и локальные функции разбора параметров. Роутер связывает HTTP-метод и путь с обработчиком контроллера. Контроллер проверяет параметры, вызывает задачи и формирует HTTP-ответ.
- `server/tasks/<действие>/` содержит Interactor и функции, используемые только в этом сценарии. Task принимает типизированные параметры и работает независимо от Express.
- `server/entities/` содержит серверные объекты состояния. Кеш TVmaze управляет хранением и сроком жизни записей.
- `server/tvmaze.ts` обращается к внешнему API и использует кеш. Контракты фронтенда и сервера лежат в `shared/` и доступны через `#shared/*`.

## API избранного

| Запрос | Успешный ответ |
| --- | --- |
| `GET /api/favorites` | `200 OK`, коллекция и количество элементов |
| `PUT /api/favorites/:id` | `201 Created` с `Location` при создании, `200 OK` при повторе. Тело содержит сериал |
| `DELETE /api/favorites/:id` | `204 No Content`, включая повторное удаление |

Некорректный идентификатор возвращает `400 Bad Request`. Если при добавлении сериал отсутствует в TVmaze, API возвращает `404 Not Found`.
После изменения клиент обновляет коллекцию отдельным `GET /api/favorites`.
